          About SecurePass AI

          SecurePass rates how strong a password is by combining automatic analysis with a few yes/no questions about things that can't be detected from the password alone.

          • No account is needed.
          • Your password is analysed in memory and is never stored.
          • We keep only anonymous features (length, character types, detected patterns), your answers and the result, to improve accuracy.
          • AI advice from Gemma is based on the analysis only — never the password itself.
          • Breaches are checked with Have I Been Pwned, which receives only the first 5 characters of the password's hash — never the password itself.
